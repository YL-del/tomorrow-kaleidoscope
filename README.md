# 明日万花筒 · 第一章 雾中宅邸（网页版）

看得见十分钟后的独眼男孩 —— 第三人称 3D 解谜游戏（three.js，零构建）。

## 本地运行

```bash
node server.js
# 浏览器打开 http://localhost:8123
```

## 操作

- WASD：上/左/下/右 移动（相对相机）
- Q / E：旋转视角
- 鼠标左键：与发光物体交互；对话时点击推进
- F（或右上角眼睛按钮）：窥探十分钟后的世界
- H（或右上角问号按钮）：分层提示

## 玩法

阿堵的「万花筒之瞳」能窥探十分钟后的一小部分细节。
按 F 进入未来画面：危险状态会看到燃烧的窗帘、倒塌的书架、飞出的钟摆……
把看到的事实带回「现在」，用道具阻止灾祸，解开三个房间（卧室 → 书房 → 门厅）。

## 结构

- `index.html` — UI 层（标题 / HUD / 对话 / 道具栏 / 窥探特效 / 结局）
- `js/data.js` — 关卡数据（房间、热点、道具、未来描述、提示）
- `js/world.js` — three.js 场景构建（房间外壳、家具、主角、未来态差异）
- `js/game.js` — 主引擎（输入、相机、交互、窥探、存档）
- `vendor/` — three.module.js + three.core.js（本地化，无外网依赖）
- `server.js` — 零依赖静态服务器（端口 8123）

存档保存在浏览器 localStorage（MINGRI_WEB_SAVE_V1）。
